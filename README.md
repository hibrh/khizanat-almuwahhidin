# خزانة الموحدين

فهرس مصوَّر لخمس مخطوطات مغربية وأندلسية من العهد الموحدي (515–668هـ / 1121–1269م)، مع بطاقة لكل مخطوط: مؤلفه وتاريخه وخطه وأهميته، والخليفة الذي كُتب في عهده.
